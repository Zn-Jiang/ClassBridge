# 隐私政策（Privacy Policy）

> 生效日期：2026-08-15
>
> 适用对象：使用 ClassBridge 家校沟通系统的家长、学生及部署本系统的班级/学校

本政策说明 ClassBridge 家校沟通系统（下称"本系统"）在提供服务过程中如何处理您的个人信息。请您在使用前仔细阅读。**如果您不同意本政策中的任何条款，请不要使用本系统，或在使用时仅通过老师当面沟通。**

---

## 1. 我们是谁

本系统是一套"家长 QQ 群 ↔ 教室电脑"的消息转发工具，由部署本系统的班级或学校（下称"部署方"）自行安装和运行。本系统由开源社区提供，部署方对其运行环境、数据存储及隐私保护措施负责。

## 2. 我们处理哪些信息

本系统在处理消息过程中可能涉及以下信息：

| 信息类型 | 说明 | 处理目的 |
|----------|------|----------|
| QQ 号码 | 您在群内发言时使用的 QQ 号 | 识别消息发送者、发送已读回执 |
| QQ 昵称 / 群名片 | 您在群内显示的名称 | 在教室电脑端展示消息来源 |
| 消息内容 | 您在群内发送的文字消息 | 转发至教室电脑、AI 意图判断 |
| 消息时间与群号 | 发送时间、所在群 | 消息排序、历史查询 |
| 消息 ID | QQ 消息的唯一编号 | 消息撤回、重发、已读回执对应 |

**我们不主动收集**姓名、电话号码、住址、支付信息等与消息转发无关的个人信息；这些信息只有您自己主动在消息中发送时才会被处理。

## 3. 信息如何使用与流转

### 3.1 常规消息转发

您（或 @机器人）发送的消息会经过以下流转：

```
家长 QQ 群 → QQ 机器人框架（NapCat）→ 转发服务器 → 教室电脑
```

- 消息**原样转发**至教室电脑显示，供学生/老师查看；
- 教室电脑确认收到后，系统可能向您发送"已读回执"；
- 您可以使用 `/撤回` 指令撤回已发送但尚未被读取的消息。

### 3.2 人工智能（AI）意图分析

为方便您不记指令也能发消息，本系统默认开启 **AI 意图分析** 功能（可联系部署方关闭）：

- 您在群内发送的**非指令、非 @机器人**的普通消息，其**文本内容**会被发送至 **DeepSeek（深度求索）官方 API**（[api.deepseek.com](https://api.deepseek.com)）进行意图分类；
- AI 仅判断该消息"是否为需要通知孩子/学生的通知类消息"（如请假、送药、带东西等），**返回结果只是一个"是/否"的判定**；
- 判定为"通知类"的消息会被自动转发至教室电脑，并可能收到系统回复提示；判定为"非通知类"的消息会被**静默忽略，不转发、不存储于转发链路**；
- **AI 请求中不包含您的 QQ 号码、昵称、群号等身份信息**，仅发送消息文本本身；
- AI 服务异常或超时时，消息**不会被转发**，您仍可通过 @机器人 的方式手动发送。

**关于 DeepSeek 处理您消息文本的详情，请参阅 DeepSeek 官方隐私政策：**

👉 [DeepSeek 隐私政策（中文）](https://cdn.deepseek.com/policies/zh-CN/deepseek-privacy-policy.html)

使用 AI 功能即表示您已了解并同意您的消息文本可能被发送至 DeepSeek 服务器进行处理。

## 4. 信息存储与保留

| 存储位置 | 存储内容 | 说明 |
|----------|----------|------|
| 转发服务器数据库 | 已发送消息全文、发送者、时间等 | 用于历史消息查询与撤回；部署方可按需清空 |
| 教室电脑本地数据库 | 消息缓存副本 | 用于断网时查看最近消息 |
| 教室电脑本地文件 | 待同步的已读回执队列 | 仅含消息 ID，不含消息内容 |
| DeepSeek API | 消息文本（AI 分析） | 其处理与保留政策以其官方隐私政策为准 |

- 消息一旦被学生在教室电脑读取，即从"未读"转为"已读"，历史消息按部署方设定的保留天数（默认 180 天）管理；
- 系统日志可能包含部分消息摘要，仅用于故障排查，部署方应定期清理。

## 5. 信息共享与第三方

- 除 DeepSeek AI 服务外，本系统**不向任何第三方**出售、出租或共享您的个人信息；
- 本系统为开源软件，代码公开可查，您可自行审计其数据处理逻辑；
- 部署方可能在法律要求或主管机关依法要求时提供相关信息。

## 6. 您的权利

- **知情权**：您有权了解本系统如何处理您的信息（即本政策）；
- **撤回权**：对已发送的消息，可在未被读取前使用 `/撤回` 指令撤回；
- **查询权**：可使用 `/查询` 指令查看自己尚未被读取的消息；
- **删除权**：可联系部署方删除服务器中与您相关的消息记录；
- **选择权**：您可以要求部署方关闭 AI 意图分析功能；关闭后，您的普通消息将不会被发送至 DeepSeek，但需要 @机器人 才能转发。

## 7. 信息安全

- 三端（服务器、教室电脑、QQ 机器人）之间通过内部令牌（token）认证通信；
- 系统数据仅在学校/班级部署方控制的环境中存储与流转；
- 因消息需在群内展示与转发，**请您不要在消息中发送敏感信息**（如身份证号、银行卡号、医疗记录等）；
- 若您怀疑信息泄露，请立即联系部署方。

## 8. 未成年人信息

本系统主要面向学生家长与教师使用。若消息中涉及未成年人信息，将仅用于家校沟通之目的。部署方应遵守相关法律法规对未成年人个人信息保护的要求。

## 9. 政策更新

本政策可能随功能更新而调整。重大变更将通过在群内发布通知的方式告知。继续使用本系统即表示您接受更新后的政策。

## 10. 联系我们

本系统的部署方为您的班级/学校。如对本政策有任何疑问，请联系您的班主任或部署方管理员。
